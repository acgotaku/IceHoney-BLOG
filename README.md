# IceHoney Blog

## Development Environment

### Setup Requirements

- [Node.js](https://nodejs.org/) v24.22.1 (see `.node-version`)
- [pnpm](https://pnpm.io/) 10.11.0

### Install dependencies

```
$ pnpm install
```

### Boot up

```
$ pnpm dev
```

Wait a few seconds and then visit `http://localhost:8080/`.

## Deployment

### Build

We can run below command to generate build files.

```
$ pnpm build
```

The build files locate at `dist` directory.
